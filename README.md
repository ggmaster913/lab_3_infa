# Лабораторная работа №3 — стек на базе Sequence

Продолжение ЛР-2. Целевой АТД — стек, построенный поверх `Sequence<T>`,
плюс несколько алгоритмов на тех же последовательностях.

## Что реализовано

| Пункт методички | Что это | Файл |
|---|---|---|
| С-3 | Стек `Stack<T>` | `include/Stack.h`, `Stack.tpp` |
| М-1 | Интерфейс `ICollection<T>` для стека | `include/Stack.h`, `Stack.tpp` |
| М-3 | Перегрузка операторов `+` и `==` | `include/Stack.h`, `Stack.tpp` |
| А-2.1 | Рекуррентная последовательность 1-го порядка (факториал) | `include/RecurrentSequence.*`, `src/RecurrentSequence.cpp` |
| А-2.2 | Рекуррентная последовательность 2-го порядка (числа Фибоначчи) | `include/RecurrentSequence.*`, `src/RecurrentSequence.cpp` |
| А-2.3 | Линейная рекуррента произвольного порядка по списку коэффициентов | `include/RecurrentSequence.*` |

### Стек

`Stack<T>` хранит указатель на `Sequence<T>` (композиция, не наследование),
поэтому работает поверх любой реализации: на массиве или на списке,
изменяемой или неизменяемой. Индекс 0 во всех операциях — вершина стека.

Операции: `Push`, `Pop`, `Peek`, `IsEmpty`, `Get`, `GetCount`, `Map`, `Where`,
`Reduce`, `Concat`, `GetSubSequence`, `FindSubsequence`, `operator+`,
`operator==`, копирование и присваивание.

Некорректные аргументы и операции на пустом стеке бросают
`std::out_of_range` или `std::invalid_argument`.

## Структура проекта

```
include/
  lab2/                 заголовки базы из ЛР-2 без изменений
  Stack.h / .tpp        стек
  NumberTheory.h        Range, IsPrime, разложение на простые множители
  RecurrentSequence.h / .tpp
                        рекуррентные последовательности
src/
  lab2/                 нешаблонная часть базы из ЛР-2 (Bit, BitSequence)
  NumberTheory.cpp
  RecurrentSequence.cpp
tests/
  Tests.cpp             тесты базы ЛР-2
  StackTests.cpp        тесты стека
  AlgorithmTests.cpp    тесты алгоритмов
ui/
  ConsoleUI.cpp         консольное меню
```

У шаблонов объявления лежат в `.h`, а тела — в `.tpp`, который подключается
в конце `.h`: компилятору нужно видеть тело шаблона там, где подставляется `T`,
поэтому вынести его в `.cpp` нельзя. Обычные функции и классы — в `src/*.cpp`.

## Сборка

Нужны CMake 3.14 или новее и компилятор с поддержкой C++17.
GoogleTest скачивается автоматически при первой настройке.

```bash
cmake -S . -B build
cmake --build build
```

## Тесты

```bash
./build/tests
```

56 тестов: 24 на базу ЛР-2, 18 на стек (в том числе с `double`, комплексными числами, строками и структурой «студент»), 14 на алгоритмы.

## Консольное меню

```bash
./build/ui
```

Разделы меню:

1. Стек — создание на массиве или списке (пустой, ручной ввод или случайные
   числа с заданным количеством и диапазоном) и все операции над ним.
2. Простые числа и разложение на множители.
3. Рекуррентные последовательности.
4. Тест производительности — время `Push` и `Pop` для стека на массиве и на списке.
